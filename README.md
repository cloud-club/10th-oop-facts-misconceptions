# 객체지향의 사실과 오해 스터디

> "객체지향이요? 클래스 잘 만들면 되는 거 아닌가요?"

『객체지향의 사실과 오해』를 함께 읽으며 객체지향에 대한 오해를 풀어가는 8주 스터디입니다.

**8주 뒤 목표:** 객체지향의 핵심 개념을 자신의 언어로 설명하고, 코드를 작성할 때 객체의 역할과 책임, 협력을 고민할 수 있는 관점을 얻어갑니다.

3. 스터디에서 2~3명이 발표하고, 다 함께 질문과 토론을 나눕니다.

## 학습 기록 제출 방법

스터디 전까지 올려 주세요. 사정이 있다면 몰아서 올려도 괜찮지만, 매주 함께 올려 주시면 더 좋아요!

1. 최신 `main`에서 `feature/영문이름-week2` 형식의 브랜치를 만듭니다.
2. 본인 이름 폴더에 주차별 Markdown 파일을 작성합니다. (형식은 자유입니다)
3. 커밋한 뒤 `[Week 2] 이름` 형식의 제목으로 PR을 올립니다.
4. 스터디가 끝나면 본인이 직접 머지합니다.

```text
김예은/
├── week2.md
└── week3.md
```
